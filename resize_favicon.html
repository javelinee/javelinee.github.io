How to use:

  1. Click the upload area above and select your current favicon.png
  2. The tool will create 3 different sizes: 32x32, 192x192, and 512x512
  3. Click "Download All Sizes" or download each individually
  4. Place the files in your project:
    • favicon.png → web/favicon.png
    • Icon-192.png → web/icons/Icon-192.png (and copy as Icon-maskable-192.png)
    • Icon-512.png → web/icons/Icon-512.png (and copy as Icon-maskable-512.png)
  5. Rebuild: flutter build web --release --base-href "/"
